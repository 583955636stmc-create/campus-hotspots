캠퍼스 보물찾기

밤의 캠퍼스에 숨은 보물 조각을 찾는 게임입니다. 25칸 중 보물 5개를 찾고 폭탄 4개는 피하세요. 마우스와 터치 모두로 조작할 수 있습니다.

장소 탐험 전력 접근률 통계

게임 화면

점수 0
남은 시간 40초
찾은 보물 0 / 5
연속 보물 0

게임 시작 버튼을 누르면 40초가 시작됩니다.

조작과 규칙

  • 조작: 마우스로 칸을 클릭하거나, 휴대전화에서 손가락으로 칸을 누릅니다.
  • 목표: 5×5 칸에 숨은 보물 5개를 찾습니다. 보물 하나는 +10점입니다.
  • 콤보: 보물을 연속으로 찾으면 두 번째부터 +2점씩 더 받습니다.
  • 폭탄: 폭탄 4개 중 하나를 밟으면 -8점이고 콤보가 초기화됩니다.
  • 종료: 40초가 지나거나 25칸을 모두 확인하면 게임이 끝납니다.
  • 다시 하기: 다시 시작 버튼을 누르면 보물 위치가 새로 배치됩니다.
